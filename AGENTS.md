# Agent Guidance

## Scope

This is a learning workshop. Preserve the progression from context and clarification to planning, creation, review, and validation. Keep the guided clients limited to VS Code Insiders and Copilot CLI. Students install both, choose one primary client, and create the application once. GitHub Copilot App is optional self-directed exploration; don't add Copilot App instructions to the core workshop.

## Implementation

- Don't create or scaffold the target project before the student approves Step 4.
- During Step 2, respect the read-only boundary and respond only to the incomplete request without inspecting repository files.
- During Step 4, treat the product specification and reviewed plan as the target contract.
- Ask rather than invent missing requirements, and let the student review consequential tool actions.
- Don't modify browser profiles or add browser extensions to the core lab.

## Validation

Run the checks named in the approved plan, report their actual output, and keep unrelated worktree changes intact.
